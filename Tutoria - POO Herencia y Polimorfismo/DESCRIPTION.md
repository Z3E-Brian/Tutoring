# Tutoria - POO Herencia y Polimorfismo

## Temas cubiertos
- Programacion Orientada a Objetos: clases, constructores/destructores
- Arreglos estaticos y dinamicos de objetos
- Herencia: clases base y derivadas
- Polimorfismo: metodos virtuales, clases abstractas, arreglos polimorficos

## Proyectos
| Proyecto | Descripcion |
|----------|-------------|
| POOEstudiante | Clase Estudiante, arreglo de objetos, calculo de mejor promedio |
| POOProducto | Clase Producto, inventario dinamico, busqueda por codigo |
| HerenciaYPolimorfismo | Clase base Transporte, derivadas Auto/Moto/Camion, metodo virtual |
| PolimorfismoEmpleados | Clase abstracta Empleado, derivadas Asalariado/PorHora/Comisionista |
