# Tutoria - Vectores y Matrices

## Temas cubiertos
- Vectores (arreglos unidimensionales): generacion aleatoria, busqueda, min/max, promedio, ordenamiento
- Matrices (arreglos bidimensionales): suma, transposicion, diagonal principal, extraccion de filas

## Proyectos
| Proyecto | Descripcion |
|----------|-------------|
| ContarElementosMayores | Contar elementos mayores a un limite en un vector |
| ContarCeros | Contar ceros en una matriz |
| MinMax | Encontrar minimo y maximo en un vector |
| PromedioVector | Calcular promedio de un vector |
| OrdenarVector | Ordenamiento burbuja de un vector |
| SumaMatrices | Suma de dos matrices 3x3 |
| TransponerMatriz | Transposicion de una matriz 4x4 |
| DiagonalPrincipal | Imprimir diagonal principal de una matriz |
| FilaDeMatriz | Extraer una fila de una matriz a un vector |
